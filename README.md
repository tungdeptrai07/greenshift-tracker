# GreenShift Tracker — Scope 1/2/3 Carbon Accounting & Net-Zero Pathway Studio

> Built for **Green Shift Hacks 2026** | Live App: **[tungdeptrai07.github.io/greenshift-tracker](https://tungdeptrai07.github.io/greenshift-tracker/)**

**GreenShift Tracker** turns daily commute, electricity grid mix, diet, travel, and cloud/AI compute inputs into an EPA/IEA-aligned Scope 1/2/3 carbon inventory with ranked decarbonization levers and exportable ESG audit reports.
